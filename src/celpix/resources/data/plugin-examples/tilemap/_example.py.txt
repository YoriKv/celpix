"""Example tilemap code format: a 3-byte cell with a split tile number.

To use: copy, remove the leading "_", edit, press F5. Code plugins run with the
app's privileges, so celPix asks before loading one.

A tilemap holds references: each cell names a tile in the tile bank the map is
bound to, plus how to draw it. A code format implements one cell layout directly
and appears in the format picker like a preset. Use it when a cell is not one
fixed-width integer: computed values, run-length schemes, variable-length
records. This layout is expressible as a preset (_packed.toml: ``bytes = 3``,
``fields = "ffff ffii ..op ppvh iiii iiii"``, little-endian) and is used here
because it exercises every method.

Contract
- Required methods: ``decode``, ``encode``, ``bytes_per_cell``, ``cell_tiles``.
- ``decode`` and ``encode`` are stateless and buffer-relative. ``decode`` returns
  a flat list of cells in file order; celPix lays it out as a grid.
- ``encode`` is the exact inverse of ``decode``.
- ``Cell`` fields: ``index``, ``palette_row``, ``priority``, ``flip_h``,
  ``flip_v``, ``visible``, ``ends_line``, ``flags``. ``decode`` must fill every
  field the format stores: a field left at its default is written back as that
  default. Put bits celPix has no field for in ``flags``.

Optional methods. Each declares an editing capability; an omitted method means
the capability is not offered.
- ``index_limit()``: highest tile number. Without it cells cannot be pointed at
  a tile (the Cell control and Edit Tiles are unavailable).
- ``palette_row_limit()``: highest palette row; allows assigning a row.
- ``has_palette_rows()``: False for a format with no palette row, so the view's
  palette row control applies. Omitted means True.
- ``transform_cell(cell, op)``: the cell after ``op``, or None to refuse.
- ``cell_fields()``: every stored field with its highest value; the per-cell
  property controls are built from it. Omitted, it is assembled from the
  methods above and can never include ``priority`` or ``flags``.
- ``has_line_flag()``: True when ``ends_line`` is stored (text formats).
- ``has_visibility()``: True when ``visible`` is stored; Clear cells then
  clears it.
- ``palette_row_granularity()``: cells ``(across, down)`` sharing one stored
  palette row. An NES nametable returns ``(2, 2)``.
- ``settle_cells(cells)``: the cells with every field the format *derives* from
  another put back in step - a palette row that follows the tile number, say.
  Called on every edit and again before an encode, so return the same list object
  when nothing changed, never a different length.
- Sprite formats only: ``size_pair()``, the two part sizes a size bit selects,
  and ``frames(cells, ctx)``, the parts grouped into frames.

Declarations. Facts celPix needs before decoding go in
``FormatInfo(declares={...})``:
  ``layout``            "text" (character codes) or "sprite" (parts at offsets)
  ``subsprite_size``    "stated": sprite parts carry their own size
  ``palette_row_base``  palette row that a cell's row 0 means
  ``indirect``, ``source_hint``, ``stamp_cells``, ``stamp_dense``,
  ``column_major``, ``cell_row_stride``: as described in _packed.toml
Example: ``FormatInfo(id=..., name=..., declares={"layout": "text"})``.
A format takes no parameters: values its own methods use are class constants.
The packed engine's other params (``stamp_stride``, ``record_shape``, page
geometry) have no effect as declarations.

Inputs. A format that needs data from outside its bytes declares
``FormatInfo(..., inputs=(InputSpec(...),))``; see ``compression/_inputs.py``.
"""

from celpix.core.tilemap import Cell, CellOp
from celpix.plugins import FormatInfo

_INDEX_BITS = 10  # the tile number's width, split 8 + 2 across bytes 0 and 2
_PALETTE_BITS = 3


class SplitCell:
    """A 3-byte cell whose tile number straddles two non-adjacent bytes.

    byte 0  tile number, low 8 bits
    byte 1  attributes: bit 0 h-flip, bit 1 v-flip, bits 2-4 palette row,
            bit 5 priority (bits 6-7 unused)
    byte 2  tile number, high 2 bits; bits 2-7 are the format's own
    """

    # `id` is stable and stored in project files; `name` is shown in the picker.
    # No `declares`: a plain grid of tile references is the default.
    info = FormatInfo(id="format.tilemap.example-split", name="Example split cell")

    def decode(self, data, ctx):
        """bytes -> list[Cell]. A trailing partial cell is dropped."""
        size = self.bytes_per_cell()
        cells = []
        for at in range(0, len(data) - size + 1, size):
            low, attr, high = data[at], data[at + 1], data[at + 2]
            cells.append(
                Cell(
                    index=low | ((high & 0x03) << 8),
                    palette_row=(attr >> 2) & 0x07,
                    priority=(attr >> 5) & 0x01,  # stored, not rendered
                    flip_h=bool(attr & 0x01),
                    flip_v=bool(attr & 0x02),
                    flags=high >> 2,  # unknown bits, preserved on write
                    # `visible` and `ends_line` keep their defaults: this
                    # format stores neither.
                )
            )
        return cells

    def encode(self, cells, ctx):
        """cells -> bytes. Values are masked to their fields: raising would
        make a map unsaveable over one out-of-range cell."""
        out = bytearray()
        for cell in cells:
            index = cell.index & 0x3FF
            attr = (
                (cell.priority & 0x01) << 5
                | (cell.palette_row & 0x07) << 2
                | (0x02 if cell.flip_v else 0)
                | (0x01 if cell.flip_h else 0)
            )
            high = (index >> 8) | ((cell.flags << 2) & 0xFC)
            out += bytes((index & 0xFF, attr, high))
        return bytes(out)

    def bytes_per_cell(self):
        return 3

    def cell_tiles(self):
        # Tiles one cell draws, (across, down). (2, 2) for a cell that is a 16x16
        # metatile; a metatile stored as four adjacent cells is (1, 1).
        return (1, 1)

    # ---- optional methods (see the module docstring)

    def index_limit(self):
        return (1 << _INDEX_BITS) - 1

    def palette_row_limit(self):
        return (1 << _PALETTE_BITS) - 1

    def has_palette_rows(self):
        return True

    def transform_cell(self, cell, op):
        # This format has no rotation bit, so rotations are refused.
        if op is CellOp.FLIP_H:
            return cell.flipped_h()
        if op is CellOp.FLIP_V:
            return cell.flipped_v()
        return None

    def cell_fields(self):
        # Keys are Cell attribute names; values are each field's highest value.
        return {
            "index": (1 << _INDEX_BITS) - 1,
            "palette_row": (1 << _PALETTE_BITS) - 1,
            "priority": 1,
            "flip_h": 1,
            "flip_v": 1,
            "flags": 0x3F,
        }


def register(registry):
    registry.register_format(SplitCell())
