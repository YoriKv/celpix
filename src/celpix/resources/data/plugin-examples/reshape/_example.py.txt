"""Example reshape. Copy this file, drop the leading underscore, edit it, and
press F5 in celPix (code plugins ask for confirmation the first time, since
they run with the app's privileges).

A reshape is a **region-scoped byte reordering**: a length-preserving permutation
applied to the *whole* region — an arcade board's plane-per-chip split joined back
together, an interleaved ROM pair woven into one stream. It runs between the
container and the decompressor, so compression and the pixel codec see bytes in
one contiguous, decodable order.

It is not a compression scheme: no extent, no end marker, nothing to scan for, and
correct only over the entire buffer, its boundaries being fractions of
``len(data)``. That is also why celPix blanks the address display and refuses to
carve slices while a reshape is active — view positions no longer name file
offsets.

**``unshape`` is optional**, and is ``reshape``'s exact inverse, run on save so
every byte returns where it came from. A reordering understood well enough to view
but not to restore ships ``reshape`` alone, and celPix opens its data read-only.

**Address permutations need no code**: a board that rotates address lines or
substitutes byte values through a table wants a TOML preset — see _bitswap.toml
and _data-lut.toml. Code is for reorderings neither engine expresses, like the
shipped split-plane joins.

This toy reshape swaps the two halves of the region; some boards store the second
half of a sprite sheet first.
"""

from celpix.core.context import PipelineContext
from celpix.core.errors import Stage
from celpix.plugins import PluginInfo


class ExampleSwapHalves:
    info = PluginInfo(
        # Ids are namespaced by stage. The folder this file sits in declares the
        # stage, so the line below is optional — stated anyway, as the other
        # examples do, so the file describes itself wherever it is read.
        id="reshape.example-swap-halves",
        name="Example half swap",
        stage=Stage.RESHAPE,
    )

    def reshape(self, data: bytes, ctx: PipelineContext) -> bytes:
        """Whole region in, whole region out — never a window of one.

        An odd byte has no partner half, so it passes through at the end rather
        than being folded in: "the last byte is not interpreted" beats shearing
        the whole image by one.
        """
        half = len(data) // 2
        return data[half : half * 2] + data[:half] + data[half * 2 :]

    def unshape(self, data: bytes, ctx: PipelineContext) -> bytes:
        """The exact inverse, so a save writes back byte-identical files.

        A half swap is its own inverse; most reshapes are not. celPix trusts the
        pair blindly and a mismatch corrupts saves, so test the round trip:
        ``unshape(reshape(x)) == x`` for odd and even lengths.
        """
        return self.reshape(data, ctx)


def register(registry):
    registry.register(ExampleSwapHalves())
